# StephFood

Site du restaurant StephFood à Lomé : carte, réservation, commande WhatsApp et espace équipe.

## Pages

- `index.html` — accueil
- `menu.html` — carte filtrable et panier
- `restauration.html` — réservation de table
- `admin.html` — espace équipe

## Espace équipe

Ouvrez `admin.html`. Tant que le mot de passe n'a pas été changé, il est indiqué sur l'écran de connexion. Changez-le dans Réglages dès la première visite.

Les commandes, messages, statuts et modifications de carte sont enregistrés dans le navigateur. Utilisez Exporter dans Réglages avant de changer d'ordinateur. Les demandes de table partent aussi vers Supabase.

## Lancer en local

```bash
npx serve .
```

Puis ouvrez l'adresse affichée.
